### Project Description

[MechMania](https://web.archive.org/web/20161003064135/https://en.wikipedia.org/wiki/MechMania) is a 24-hour AI hackathon held annually at the Reflections Projections tech conference hosted by ACM at UIUC. 

I was on the MechMania staff in 2018 & 2019. We take a year to build a game in relative secrecy. The game is unveiled at the ceremony, after which competitors have 24 hours to build a bot to best other teams.

## Contribution: Visualizer Team Lead

The visualizer team is responsible for receiving streams of game state data from the server and visualizing the game in Unity. I joined in MechMania 24 as a contributor and was the visualizer team lead for MechMania 25.

Contributions included:
<ul class="mb-0">
  <li>Modified a JSON deserializer for our game state data</li>
  <li>Developed a map generation tool to streamline the game design team's workflow
  </li>
  <li>Implemented visualizer UI and dynamic orthographic camera movements</li>
  <li>Coordinated with server team to ensure readiness by the one year deadline</li>
</ul>

While <a href="https://www.twitch.tv/mechmania_tv/about">streaming on twitch</a>, we were the top programming stream on twitch for its duration with 585 viewers!
